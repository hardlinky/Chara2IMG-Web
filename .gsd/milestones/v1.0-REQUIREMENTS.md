## v1 Requirements

### Workflow Import

- [x] WFLO-01: User can load a custom ComfyUI workflow JSON file into the web app.
- [x] WFLO-02: User can validate that the uploaded workflow JSON is structurally valid before running jobs.
- [x] WFLO-03: The app preserves the full original workflow JSON as template source.
- [x] WFLO-04: User can reuse the loaded workflow template across multiple runs.

### Dynamic Inputs

- [x] INPT-01: Generated controls from supported workflow nodes.
- [x] INPT-02: Editable text and multiline inputs.
- [x] INPT-03: Editable numeric inputs (int/float).
- [x] INPT-04: Editable boolean inputs.
- [x] INPT-05: Editable paired dimension inputs.
- [x] INPT-06: Editable image inputs.
- [x] INPT-07: Edited values applied into job-ready payload before submission.
- [x] INPT-08: Grouping/ordering preserved for repeatable use.

### Jobs

- [x] JOBS-01: Submit job with current workflow/inputs.
- [x] JOBS-02: See current status for each submitted job.
- [x] JOBS-03: Poll until complete/failed/cancelled/timeout.
- [x] JOBS-04: Cancel queued/running job.
- [x] JOBS-05: Rerun prior job with saved inputs.
- [x] JOBS-06: Load prior job inputs into Input tab.
- [x] JOBS-07: Remove job from visible list.
- [x] JOBS-08: Keep enough local job history for normal usage.

### Outputs

- [x] OUTP-01: View generated outputs for completed jobs in an Outputs/Output tab.
- [x] OUTP-02: View multiple generated images for a single job.
- [x] OUTP-03: Keep each output associated with source job.
- [x] OUTP-04: Browse outputs in a gallery-oriented view.

### Access and Keys

- [x] AUTH-01: User can provide own Runpod API key.
- [x] AUTH-02: User can remember key in browser-local storage.
- [x] AUTH-03: Backend forwards lifecycle calls without long-term key persistence.
- [x] AUTH-04: Invited-user access model is supported.
