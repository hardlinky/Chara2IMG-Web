**Directory resolution (top of file, outside functions):**

```ts
const PROJECT_ROOT = resolve(dirname(fileURLToPath(import.meta.url)), "../../..");

function resolveDir(envNew: string, envLegacy: string, defaultVal: string): string {
  return resolve(PROJECT_ROOT, process.env[envNew]?.trim() || process.env[envLegacy]?.trim() || defaultVal);
}

const JOB_TMP_BASE = resolveDir("JOBS_TMP_DIR", "RECENT_JOBS_STORAGE_DIR", JOBS_TMP_DIR_DEFAULT);
const JOB_ARCHIVE_BASE = resolveDir("JOBS_ARCHIVE_DIR", "PINNED_IMAGES_STORAGE_DIR", JOBS_ARCHIVE_DIR_DEFAULT);
```

**Exported path helpers:**

```ts
export function getJobTmpDir(): string { return JOB_TMP_BASE; }
export function getJobArchiveDir(): string { return JOB_ARCHIVE_BASE; }
export function getJobImagePath(jobId: string, fileName: string, archived = false): string {
  const base = archived ? JOB_ARCHIVE_BASE : JOB_TMP_BASE;
  return join(base, "jobs", jobId, fileName);
}
```

**`ensureJobStoreDirs()` — call once at server startup:**

```ts
export async function ensureJobStoreDirs(): Promise<void> {
  await mkdir(join(JOB_TMP_BASE, "jobs"), { recursive: true });
  await mkdir(join(JOB_ARCHIVE_BASE, "jobs"), { recursive: true });
}
```

**`createJob(record: JobRecord, inputs: JobInputs): Promise<void>`**
- Compute `jobDir = join(JOB_TMP_BASE, "jobs", record.jobId)`
- `await mkdir(jobDir, { recursive: true })`
- `await writeFile(join(jobDir, "job.json"), JSON.stringify(record, null, 2), "utf8")`
- `await writeFile(join(jobDir, "inputs.json"), JSON.stringify(inputs, null, 2), "utf8")`

**`readJob(jobId: string): Promise<JobRecord | null>`**
- Read `join(JOB_TMP_BASE, "jobs", jobId, "job.json")` — return null if ENOENT
- Parse JSON, return as `JobRecord`

**`updateJob(jobId: string, updates: Partial<JobRecord>): Promise<JobRecord | null>`**
- `readJob(jobId)` → return null if not found
- Merge: `const next = { ...existing, ...updates }`
- Write back to job.json (same path as readJob)
- Return `next`

**`deleteJob(jobId: string): Promise<void>`**
- `await rm(join(JOB_TMP_BASE, "jobs", jobId), { recursive: true, force: true })`

  <name>Task 2: Add listJobs, archiveJob, and purgeExpiredJobs to jobStore.ts</name>

  <action>
Append the following three exports to the file created in Task 1.

**`listJobs(): Promise<JobRecord[]>`**
- Read dir: `await readdir(join(JOB_TMP_BASE, "jobs"), { withFileTypes: true })`
- For each entry that `isDirectory()`, attempt `readJob(entry.name)`; collect non-null results
- Return array sorted by `submittedAt` descending (most recent first)

**`archiveJob(jobId: string): Promise<boolean>`**
- Source: `join(JOB_TMP_BASE, "jobs", jobId)`
- Dest: `join(JOB_ARCHIVE_BASE, "jobs", jobId)`
- If source does not exist, return `false`
- `await mkdir(join(JOB_ARCHIVE_BASE, "jobs"), { recursive: true })`
- Copy recursively: read all files in source dir via `readdir`, then for each file
  `await copyFile(src, dest)` (use `node:fs/promises` copyFile)
- After all files copied, write `job.json` in archiveDir with `isArchived: true` (add field to copy)- Also call `await updateJob(jobId, { isArchived: true } as Partial<JobRecord>)` to stamp the tmp dir
  record so `listJobs()` returns it when filtering by `isArchived`- Do NOT delete source — tmp TTL handles that separately
- Return `true`

**`purgeExpiredJobs(): Promise<string[]>`**
- `listJobs()` → filter where `record.expiresAt !== null && new Date(record.expiresAt) < new Date()`
- For each expired job: `await deleteJob(record.jobId)` — but check archive first:
  check if `join(JOB_ARCHIVE_BASE, "jobs", record.jobId)` exists via `stat()` (catch ENOENT);
  only delete tmp dir if archive exists OR if expiresAt is more than 24h in the past
- Return array of deleted jobIds

Note: Add `isArchived?: boolean` to `JobRecord` in `src/shared/contracts/jobs.ts`. This enables
`{ isArchived: true } as Partial<JobRecord>` in the `updateJob` call without an unsafe cast, and allows
the archive copy to set it via normal field spread when writing the archive job.json.
